# SCREEN (from Fallout 2 Realtime 2026-11-18, his „když nemířím na item v inventáři tak Bčko mi vypne inventory“, then
# „i F1“): in the inventory B over an item still puts it in hand B; over anything else -- an empty row, an empty hand, the
# dude, DONE -- it closes the screen, like BACK. DONE wears a dark B disc, as the loot window's does (his „ano, dej tam
# B“). `screen` = the presented frame.
#   1 the inventory, the pointer on nothing           2 after B: the world
#   3 the inventory again, the pointer on row 0 (the pistol)
#   4 after B: the pistol in hand B, the screen still up
#   5 after B again, on the now empty row: the world
