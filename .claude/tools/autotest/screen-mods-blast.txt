# The MODS row "Blast ring" (from Fallout 2 Realtime 2026-11-08): the pause menu, PREFERENCES, X for MODS, then up
# three rows from the top (the list wraps) onto it. Shot on Awareness (the default), LB, shot Off, RB back to
# Awareness, B out of all three.
# 26 rows at 480 lines: the window is 428 of its 430 px, pitch 12 (the lineH + 2 floor). Every row must still fit,
# the help band below them. A 27th row would grow the window past 430.
name screen-mods-blast
map DESERT1.MAP
seed 1
duration 16
dude tile 20100 rot 2

# START tapped: the pause menu opens on the release, its highlight on SAVE GAME
open 1000 options
# SAVE -> LOAD -> PREFERENCES, A opens it
tap 2200 DOWN
tap 2700 DOWN
tap 3200 A
# X opens MODS from Preferences
tap 4600 X
# the top row wraps to the bottom: Internal resolution, Screen resolution, Blast ring
tap 5800 UP
tap 6300 UP
tap 6800 UP
shot 7600
tap 8400 LB
shot 9200
tap 10000 RB
# B closes MODS, B cancels Preferences, B shuts the pause menu
tap 11000 B
tap 12200 B
tap 13400 B
note 15000 the world should be back

expect \[FLOW/autotest\] end why=time .* modal=-1
